# Hands-on 1 (Module 2): Dockerizing the AIOps Assistant

## Goal
Package the Streamlit-based AIOps Assistant into a Docker container for consistent deployment across different environments.

## Prerequisites
- Docker installed and running on your machine.
- Completion of Module 1.

## Steps

### 1) Review the Dockerfile
Navigate to `module-1/mini-aiops-rag-demo/` and examine the real `Dockerfile` in that folder.

This lab is intentionally aligned to the capstone repo (`AIOps-recommender/`), which also ships a Dockerfile and expects environment variables to be injected at runtime.

### 2) Hands-on (moved to Module 3)
To avoid duplicating deployment content, the step-by-step Docker work is covered in:
- `module-3/hands-on-1-dockerfile/README.md`
- `module-3/hands-on-2-local-container-test/README.md`

After completing the Module 3 Docker labs, come back to Module 2 Hands-on 2 and Hands-on 3 to continue the RAG + LLM upgrades.
